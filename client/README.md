# client

Frontend của Docs Clone — Next.js (App Router) + TypeScript + Tailwind CSS v4.

## Lệnh

```bash
pnpm dev         # chạy dev server (Turbopack)
pnpm build       # build production
pnpm start       # chạy production build
pnpm typecheck   # kiểm tra type
pnpm lint        # oxlint
```

## Cấu trúc

```
src/
  app/          # routes (App Router)
  components/   # React components
  hooks/        # custom hooks
  api/          # API client calls
```
